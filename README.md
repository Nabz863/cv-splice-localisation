# Localising spliced regions in images: a controlled comparison

COMS4036A/COMS7050A Computer Vision project, Wits. Nabeel Mahomed (2671907),
Jonathan Lewis (2660425).

Pixel-level splice localisation on CASIA v2.0 (1,822 splicing image/mask pairs),
compared across five rungs that differ in where their knowledge comes from:

| Rung | Method | Knowledge source |
|---|---|---|
| 1 | Error Level Analysis, thresholded | JPEG compression physics, 1 parameter |
| 2 | ELA + Potts MRF, exact graph cut | + a spatial prior, 2 parameters |
| 3 | SAM2, unprompted | general-purpose segmentation, no forensics |
| 4 | U-Net with a constrained first layer | ~1,093 labelled masks |
| 5 | U-Net + the same MRF | learned evidence + spatial prior |

At beta = 0 rung 2 reduces exactly to rung 1 and rung 5 to rung 4
(`src/methods/test_mrf.py`), so any gain between them is the prior's alone.

## Setup

```bash
export DATASETS=/path/to/datasets      # CASIA v2 lives in $DATASETS/casia2
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt        # plus a CUDA build of torch for training
```

Every script is run from the repository root.

## Reproducing every number in the report

Three jobs; the two GPU jobs run at the same time. All are safe to resubmit.

```bash
sbatch slurm/rerun_unet.sbatch        # GPU: full-data rungs 4/5, AUC, mechanism, ~20 h
sbatch slurm/rerun_datasize.sbatch    # GPU: data-size curve + stabiliser runs, ~20 h
DATASETS=... bash scripts/rerun_cpu.sh  # CPU: rung 1 choice, ICM, tests, then every
                                        # table and figure (after both GPU jobs)
```

Every U-Net in the report, at every training-set size, is trained by one script,
`cache_logits.py`, under one config. Each saved model and logits file carries a
JSON sidecar with that config (`refine_meta.py`), and anything produced under a
different one is refused, never reused. Old outputs are moved to `results/stale/`,
never deleted.

## Pipeline, in order

Each step writes into `results/`; later steps read what earlier ones wrote.
Trained models (`results/models/`) and cached logits (`results/logits/`) are not
committed - they are regenerated by the GPU steps.

**Data**
1. `src/data/build_manifest.py` - pairs splicing images with masks, logs the 6
   excluded for size mismatch. `build_manifest.py Tp_S_` does the same for copy-move.
2. `src/data/stratify_folds.py` - 5 folds stratified by host-image category.

**Checks**
3. `src/eval/test_metrics.py`, `src/methods/test_mrf.py`, `src/report/test_overlap.py`,
   `src/methods/sanity_auc.py`

**Rung 1 (choosing the evidence)**
4. `compare_variants.py` - pixel AUC of five candidate cues -> `cue_auc.csv`; ELA wins.
5. `tune_ela.py` - re-compression quality and window -> `ela_tuning.csv`.
   Both take `HOLDOUT=k` (default 0) to leave test fold k out of the choice;
   `rerun_cpu.sh` runs all five and `build_tables.py` checks they agree.
   `diagnose_texture.py` -> `texture_corr.csv` shows why the noise cues failed;
   `diagnose_rung1.py` and `dump_examples.py` are the exploratory diagnostics.

**Rung 2**
6. `run_mrf.py` - per-image counts at every (tau, beta) -> `rung2_grid.npz`.
7. `nested_pairs.py` (all 20 pairs, cross-checked by `build_tables.py`),
   `plot_surface.py` (the objective surface).
8. `icm_vs_graphcut.py` - the same grid solved with ICM -> `rung2_grid_icm.npz`.

**Rungs 4 and 5** (GPU and CPU deliberately in separate processes)
9. `overfit_batch.py` - wiring check before any real run.
10. `compare_stabilisers.py` - the fp16 divergence investigation.
11. `cache_logits.py` (GPU) -> `sweep_cached.py` (CPU) -> `merge_refine.py`, for all
    data (`rerun_unet.sbatch`) and with `N_TRAIN=50/150/400/800`, `SUFFIX=_n50` ...
    for the data-size curve (`rerun_datasize.sbatch`).
12. `sweep_perimage.py` - per-image counts at every (tau, beta), for selecting by
    per-image F1.

**Further analyses**
13. `per_category.py`, `copymove_matched.py`, `image_auc_classical.py`, at the single
    operating point `build_tables.py` derives and checks (tau 0.75, beta 8).
14. per pair (`TAG=t0v1` ... `TAG=t4v3`): `cache_auth_logits.py` (GPU) ->
    `image_auc_unet.py` -> `select_summary_unet.py`
15. `mechanism.py` (where the prior's corrections fall), `fig_qualitative.py`

**Report**
16. `src/report/build_tables.py` - every quoted number, from the files above,
    with cross-checks -> `results/tables/`
17. `src/report/make_figures.py` - every figure, from the tables only; refuses to
    save any figure with overlapping labels -> `results/figures/`

## Where a number comes from

Every figure reads `results/tables/`, and `build_tables.py` names the source file
of every table in its docstring. Training curves and stabiliser histories are in
`wandb/` (offline runs) and on W&B.
